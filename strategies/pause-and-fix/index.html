Pause and Fix

Responding to a common misconception

Use Pause & Fix when a common gap means continuing would reinforce an error or make the next step inaccessible. Stop briefly, repair the precise issue and return to a fresh attempt.

How to do it

  1. Identify the common gap. Use responses or work to locate the knowledge or decision causing widespread difficulty.
  2. Stop and frame the repair. Secure attention, name the issue neutrally and explain why this short pause matters.
  3. Re-model differently. Use a smaller step, contrasting example or clearer representation that addresses the error directly.
  4. Give a fresh check. Require every student to apply the idea to a related example before you reveal the answer.
  5. Resume proportionately. Continue when the evidence supports it, with targeted follow-up for remaining gaps; extend the repair when the class is still insecure.

What it sounds like

“Pause. Several answers use the mass in place of the volume. We will model that distinction once, then everyone will try a new example.”

Do

  • Match the repair to the shared error.
  • Secure attention before re-explaining.

Avoid

  • Stopping the class for every interesting error.
  • Treating copied corrections as proof the issue is fixed.

Top tips

  • Pause for a consequential pattern. A few isolated slips may need individual feedback rather than stopping productive class work.
  • Change the explanation. Repeating the same long account more loudly rarely addresses the faulty idea.
  • Keep the repair bounded. State the specific distinction you are fixing and show it with one clear example.
  • Keep secure students thinking. Ask them to explain the misconception or test a useful variation rather than sit through unnecessary repetition.
  • Recheck before resuming. Use changed surface details and the same conceptual demand so students must apply the repair.

In the classroom

In Maths practice, several pupils apply the same invalid cancellation. The teacher stops, identifies the exact condition for a valid move and contrasts the two cases. Everyone then attempts a new item. Once the class pattern is secure, practice resumes with individual follow-up for remaining gaps rather than a complete restart of the topic.

Use it for Individual Development

Example goal

I will stop the class briefly to fix a common misconception when I see it, so that students correct the error before continuing.

Peer observer look-fors

  • The teacher stops the class when a common error appears.
  • The fix is quick and precise.
  • Pupils re-check and apply the correction.

Quick check of impact

Look for the misconception in subsequent work. Note whether it decreases.

Adapt the goal to your class and subject. See writing a precise goal and peer observation.

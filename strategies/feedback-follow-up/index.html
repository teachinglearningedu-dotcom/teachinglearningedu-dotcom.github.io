Feedback follow-up

Checking improvement on a new task

Use feedback follow-up to find out whether the learning improved beyond the original correction. A new attempt gives more useful evidence than a rewritten answer alone.

How to do it

  1. Identify the intended improvement. State the knowledge, decision or feature the feedback should change.
  2. Prepare a related task. Retain the conceptual demand while altering the example enough to require application.
  3. Deliver feedback and action time. Model or prompt the correction and require the student to practise the repaired idea.
  4. Collect an independent attempt. Reduce access to the original solution and inspect both answer and reasoning.
  5. Return after a delay. Use a later retrieval or application task and decide whether further explanation, rehearsal or support is necessary.

What it sounds like

“You have corrected the worked example. Now close it and try this new case. Explain the decision that prevents the same error.”

Do

  • Use independent application on a fresh task.
  • Record remaining gaps for later teaching.

Avoid

  • Counting a copied model as improved understanding.
  • Never returning to the learning after the feedback lesson.

Top tips

  • Plan the new item before feedback. This keeps the improvement focus precise and prevents the follow-up becoming an afterthought.
  • Keep the demand comparable. An unexpectedly harder question makes it difficult to interpret whether the correction helped.
  • Change enough to require thinking. A clone with one number swapped may reward imitation.
  • Revisit after a delay. Immediate success can depend on recent memory of the teacher’s explanation.
  • Inspect the process. A correct final answer may still hide the original faulty reasoning.

In the classroom

After feedback on a misconception, pupils try a fresh question with comparable demand and no visible original solution. The teacher inspects the reasoning, not just the final answer. The learning returns in a later quiz. This separates immediate successful correction from the student’s ability to use the repaired idea independently over time.

Use it for Individual Development

Example goal

I will give students a new, similar task after feedback, so that I can see whether learning has improved beyond the corrected piece.

Peer observer look-fors

  • A new task assesses the same learning.
  • Pupils apply the feedback independently.
  • Improvement is evident.

Quick check of impact

Compare performance on the follow-up task with the original.

Adapt the goal to your class and subject. See writing a precise goal and peer observation.

Feedback as detective work

Diagnosing the underlying cause of a response before deciding what information, prompt, model or practice will move learning forward.

What it is: Diagnosing the underlying cause of a response before deciding what information, prompt, model or practice will move learning forward.

Why it helps: The same visible error can arise from different causes. Treating feedback as diagnosis avoids generic correction and helps the teacher target knowledge, process, attention, fluency or self-regulation.

Use it when: when an error persists, appears across several students or does not respond to the first correction.

Implementation sequence

Define the intended performance and gather the student's current evidence.

Ask the student to explain the choice or process that produced the answer.

Classify the likely cause rather than merely naming the surface error.

Choose the smallest response matched to that cause.

Require correction and a similar transfer item.

Record a curriculum or teaching issue when the pattern is widespread.

DODON'T
Use questions to reveal the student's model of the task. Distinguish missing knowledge from failure to apply known knowledge. Escalate from prompt to clue to model only as required. Correct the final answer without identifying the faulty step. Assume carelessness when knowledge may be insecure. Give the same feedback code to errors with different causes.

Check for impact

The selected response fixes the cause, not just the example.

The student succeeds on a related but non-identical task.

Sources informing this profile: DistilED: Feedback as Detective Work; StepFinder: Classify Student Errors.

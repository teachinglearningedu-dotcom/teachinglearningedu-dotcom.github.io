Purpose

The We Do is the bridge between teacher modelling and independent practice. Pupils attempt the same underlying skill with support while the teacher gathers evidence about who is ready to work alone and who needs more guided practice.

Choose the question carefully

The We Do should require thinking without becoming a completely new problem. If it is almost identical to the I Do, pupils can copy a pattern without understanding. If it is too different, the teacher cannot tell whether the new learning itself is secure.

Board setup

The project summary recommended keeping the I Do visible on one side and revealing the We Do separately, allowing pupils to use the model without confusing the two examples.

Step-by-step MWB version

  • 1. Reveal the We Do only after the I Do is complete.
  • 2. Ask pupils to complete only the first step on their mini whiteboards.
  • 3. Scan the class.
  • 4. Write or confirm the correct step.
  • 5. Proceed to the next step only when the evidence justifies it.

Tick Trick → What If → Reset → Extension

  • Tick Trick: pupils compare their layout / working with a model and audit where marks or ticks are gained.
  • What If: change as little as possible in the question so pupils adapt their existing working rather than starting from scratch.
  • Reset: use a genuinely different question that requires a clean board and a fresh application of the method.
  • Extension: pose a question or variation pupils have not yet seen, moving beyond simple reproduction.

Recommended sequence from the project transcription

I Do → step-by-step We Do → Tick Trick → What If → Reset → Extension. The exact number of variations depends on the complexity of the procedure; the project notes cautioned against forcing multiple “What If” changes when the procedure is too large or the alterations would create excessive load.

Do / avoid

DoAvoid
Keep the I Do available as a model.Jumping straight from I Do to long independent practice.
Use all-pupil response methods during guided practice.Using an identical clone that rewards pattern copying.
Change enough to require thinking, but not so much that you are testing something else.Making the We Do so novel that failure is uninterpretable.
Extend guided practice for pupils who are not yet secure.Moving on because the most vocal pupils can do it.

Explicit link to the BSCS model

  • Secure learning through practice: This is the core guided-practice phase before responsibility is handed over.
  • Check and adapt: Every We Do response is data about readiness for independence.
  • Drive thinking for all: MWBs and step-by-step responses keep participation high.
  • Explain: The I Do remains visible and can be re-modelled if the check shows pupils are not ready.

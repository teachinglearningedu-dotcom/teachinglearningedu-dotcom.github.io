Activating prior knowledge

Bringing the specific existing knowledge needed for new learning into working memory and making the connection explicit.

What it is: Bringing the specific existing knowledge needed for new learning into working memory and making the connection explicit.

Why it helps: New learning is understood by attaching it to existing schema. Activation reduces load, exposes missing prerequisites and makes meaningful rather than superficial connections.

Use it when: before a new concept, representation or procedure that depends on previously taught ideas.

Implementation sequence

Identify the smallest set of prior knowledge that genuinely supports the new idea.

Retrieve it through a brief question, example, diagram or comparison.

State the connection explicitly, moving from broad context to the precise link.

Ask students to process the relationship by explaining, predicting or comparing.

Check meaning rather than merely whether the old fact was recalled.

DODON'T
Use a prerequisite check separately from spaced Do Now retrieval when needed. Supply missing background knowledge before building on it. Return to the connection during the explanation. Activate interesting but irrelevant associations. Ask only 'Who remembers...?' and rely on volunteers. Assume prior teaching means prior knowledge is currently accessible.

Check for impact

Students can state how the new idea builds on or differs from previous learning.

Misconceptions caused by missing prerequisites reduce.

Sources informing this profile: DistilED: Activating Prior Knowledge; BSCS Explain phase.

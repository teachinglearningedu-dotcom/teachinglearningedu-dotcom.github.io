Core idea

Atomisation means breaking a routine, concept or performance down into the smallest teachable and assessable pieces needed for success. In the BSCS adaptation developed in the project, the key value is not the maths-specific taxonomy itself; it is the planning discipline of identifying what pupils must already know before the new explanation can work.

The BSCS planning routine: ATOMISE BEFORE YOU EXPLAIN

  • 1. Start with the endpoint: what will successful performance look like?
  • 2. Select a representative example or task that genuinely embodies the new learning.
  • 3. Atomise what pupils need to know or do to succeed on that example.
  • 4. Separate prerequisite atoms from genuinely new atoms.
  • 5. Plan how prerequisite atoms will be checked before the Explain phase.
  • 6. If the prerequisite check is insecure, fix the gap and re-check before layering on the new idea.
  • 7. Use the new atoms to decide the order and size of the explanation steps.

Decision rule from the project summary

Where prerequisite knowledge is not secure for a substantial proportion of the class, the response is not to press on with the planned explanation. The project summary used an approximate 80% security threshold: below that, explain or fix the prerequisite and then re-check.

Important distinction

Atoms are a teacher planning tool, not a list of lesson objectives to display to pupils. The purpose is to make expert knowledge structure visible to the teacher so that explanations and checks are more precise.

Explicit link to the BSCS model

  • Lesson preparation: Directly strengthens anticipation of barriers, sequencing and planning the explanation.
  • Explain: Determines the smallest coherent steps and what can be treated as known versus what requires explicit teaching.
  • Check and adapt: Prerequisite checks generate actionable evidence before new content is introduced.

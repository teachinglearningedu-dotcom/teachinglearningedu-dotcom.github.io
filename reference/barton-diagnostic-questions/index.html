Definition and purpose

A diagnostic question is designed to provide a window into pupils’ thinking so that the teacher can make a better instructional decision. In practice, the project summary focused on multiple-choice questions with one correct answer and three distractors, where each distractor represents a plausible misconception or error.

What diagnostic questions can assess

  • Factual recall.
  • Procedural knowledge, including “who is correct?” comparisons.
  • Conceptual understanding, again often through comparing reasoning rather than only final answers.

Question-quality criteria

  • Distractors must be plausible and diagnostic, not silly.
  • There should be one unambiguously correct answer.
  • Prefer a single-step interpretation where possible.
  • Avoid grammatical cues, option-length clues and other test-wise shortcuts.
  • Design so pupils cannot arrive at the correct option for the wrong reason.

Five-step classroom routine

  • 1. Think in silence.
  • 2. Working out is allowed where appropriate.
  • 3. Rehearse an explanation for the chosen answer.
  • 4. No looking at other pupils’ responses.
  • 5. Show the answer on the common cue.

The project notes used roughly 5–10 seconds thinking time for many questions and recommended launching the routine with non-subject examples so pupils learn the mechanics before the diagnostic content matters.

Supercharging the question

  • Hide the answer options first and ask pupils to generate an answer before seeing the choices.
  • After identifying the correct option, ask why someone might choose each wrong answer.
  • Ask pupils to change a wrong option so that it becomes correct.
  • Use the response pattern to form temporary flexible groups while secure pupils complete deeper explanation or extension.

Do / avoid

DoAvoid
Write distractors from real misconceptions.Using arbitrary wrong answers merely to fill four options.
Give thinking time before the reveal.Showing options so early that recognition replaces retrieval when generation is possible.
Require pupils to commit simultaneously.Revealing the correct answer before the whole-class vote.
Ask about the reasoning behind wrong answers.Treating the percentage correct as the only useful information; the distractor pattern matters.
Use the response pattern to decide what happens next.Using ambiguous multi-step wording that makes the diagnosis unclear.

Explicit link to the BSCS model

  • Check and adapt: Each distractor should indicate a different likely misconception, making the next instructional move more precise.
  • Lesson preparation: Strong diagnostic questions are planned around anticipated errors; they are difficult to improvise well.
  • Drive thinking for all: Simultaneous ABCD / MWB responses make every pupil commit.
  • Explain: The diagnosis can determine exactly what must be re-explained and what can be left alone.

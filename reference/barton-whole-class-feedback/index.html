Core idea

The purpose of feedback is to change what pupils think or do, not to maximise the amount the teacher writes. The project summary therefore treated whole-class feedback as a diagnostic and instructional process: identify class patterns, select the most important issues, teach them, re-check them and create personalised future retrieval where needed.

Diagnose patterns efficiently

  • Use ticks and crosses or another light-touch marking system to see patterns quickly.
  • Use barometer pupils if reading every script in detail would not change the class-wide diagnosis.
  • Annotate a blank copy of the assessment rather than writing repeated comments on every pupil’s paper.
  • Photograph or capture excellent examples and useful errors for modelling / Show Call.
  • Select around three widespread misconceptions for whole-class treatment. Isolated or careless errors may be better handled through retrieval opportunities rather than a long whole-class explanation.

Prepare the feedback lesson before returning work

The project summary emphasised giving the instructional feedback before returning the marked work, so attention stays on the model and the re-check rather than on individual scores and corrections.

Model → Re-check → Stretch

  • 1. Model the misconception or question type clearly.
  • 2. Ask an equivalent re-check question, ideally through mini whiteboards so everyone commits.
  • 3. Use approximately 80% as the threshold for whether the class is ready to move on.
  • 4. If secure, ask a harder stretch / variation question; if not, model again or change the explanation and re-check.
  • 5. Repeat this cycle for two or three high-value issues. The project summary suggested roughly 20 minutes as a useful scale for the main WCF sequence rather than trying to reteach an entire assessment.

Detective work and Review Cards

A strong end-point is a blank-copy “detective work” task in which pupils reconstruct a perfect version or identify how each item should have been approached. When work is finally returned, personalised Review Cards are more valuable than simply copying corrections: they turn individual errors into future retrieval targets.

Departmental routine captured in the project summary

Ticks/crosses + scores → identify three questions / issues → Model → MWB Re-check → Stretch → return work → Review Cards / future retrieval.

Explicit link to the BSCS model

  • Feedback to improve: Directly aligns: review patterns, address misconceptions, model improvement and ensure pupils act on feedback.
  • Check and adapt: The re-check determines whether to re-teach, move on or stretch.
  • Secure learning through practice: Equivalent questions provide immediate practice of the corrected idea rather than passive listening.
  • Drive thinking for all: MWB re-checks make the feedback episode accountable for everyone.

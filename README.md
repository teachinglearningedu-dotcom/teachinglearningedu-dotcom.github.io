# BSCS Teaching & Learning website

- The live site is the `main` branch; this `source` branch rebuilds it.
- Rebuild: `python3 build.py src out https://YOUR-SITE-URL`
  - `implementation.py`: evidence rating, core flag, example goal, look-fors and impact check for each strategy
  - `content.py`: pupil needs pages and Individual Development guidance
  - `src/`: the original site export (strategy guide data and reference pages)

Publish: Settings → Pages → Deploy from a branch → `main` / `/docs`.

Pupil need

Learning time is lost at the start, transitions or end

Lessons start slowly, attention drifts during instructions and transitions take longer than they should.

Where to start

Consistent, rehearsed routines protect attention and learning time. Use the agreed BSCS routines first, then teach and rehearse any that are unreliable.

Strategies to consider

Choose one. Start with a core strategy unless another fits your class better.

  1. Entry routines Established practiceCore strategy

    Use the agreed BSCS entry routine to make the move from corridor to independent learning warm, predictable and purposeful. Students should know where to go, what to prepare and how to begin.

    Example goal: I will meet students at the door and use the agreed BSCS entry routine consistently, so that students settle quickly and start the Do Now independently.

  2. Signal for attention Established practiceCore strategy

    Use the agreed BSCS signal before instructions, explanations and transitions. Secure readiness before speaking so the beginning of the message reaches the whole class.

    Example goal: I will use the agreed BSCS signal and wait for full attention before speaking, so that every student hears the start of instructions and explanations.

  3. Clear instructions and front-loading Established practice

    Use front-loading when students begin responding or moving before they have heard the participation instructions. Say how to respond before giving the content that will capture attention.

    Example goal: I will say how students should respond before I give the question or task, so that students start correctly and fewer call out or start too early.

  4. Classroom transitions Established practice

    Use a taught transition to move students from one activity to the next without losing attention or learning time. Specify how to stop, shift resources and begin the new demand.

    Example goal: I will teach a clear stop–shift–start transition, so that students move between activities quickly and begin the next task without lost learning time.

  5. Teaching and rehearsing classroom routines Research-informed

    Use this when a repeated classroom process is unreliable. Routines become useful when students understand, practise and rehearse the exact actions, rather than hear a rule once.

    Example goal: I will teach, model and rehearse one unreliable classroom routine, so that students carry it out quickly and correctly without repeated reminders.

  6. Precorrections Research-informed

    Use a precorrection when a predictable situation repeatedly produces the same difficulty. Prompt the desired action immediately before that moment, using the pattern you have noticed.

    Example goal: I will give a short precorrection immediately before predictable problem moments, so that students get it right first time rather than needing correction.

  7. Exit routines Established practice

    Use the agreed BSCS exit sequence to finish learning, restore the room and move students calmly into the corridor. Plan sufficient time for practical equipment and resource return.

    Example goal: I will plan enough time for the agreed exit routine, so that students finish learning, tidy up and leave calmly and on time.

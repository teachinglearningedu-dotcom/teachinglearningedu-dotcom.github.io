Pupil need

Pupils keep making the same mistakes

The same errors recur across lessons and assessments, even after you have corrected them.

Where to start

Plan for the misconception before the lesson, expose it deliberately and check the fix on a fresh question. Feedback only helps when pupils act on it.

Strategies to consider

Choose one. Start with a core strategy unless another fits your class better.

  1. Anticipating misconceptions and planning how to uncover them Research-informed

    Use this when students repeatedly make the same plausible error. Anticipate the reasoning behind that error so the lesson exposes and repairs it rather than merely announcing the correct answer.

    Example goal: I will plan the most likely misconception for each new idea and a question that exposes it, so that students confront and correct the error during the lesson rather than in assessments.

  2. Diagnostic questions Research-informed

    Use diagnostic questions when you need to see which misconception or decision is causing difficulty. A well-designed wrong option tells you something useful about students’ thinking.

    Example goal: I will use one planned multiple-choice diagnostic question per lesson, with wrong options built on common errors, so that students reveal precisely what they misunderstand.

  3. Pause and Fix Research-informedCore strategy

    Use Pause & Fix when a common gap means continuing would reinforce an error or make the next step inaccessible. Stop briefly, repair the precise issue and return to a fresh attempt.

    Example goal: I will stop the class briefly to fix a common misconception when I see it, so that students correct the error before continuing.

  4. Confidence scores Research-informed

    Use confidence scores alongside answers to identify uncertainty and confidently held errors. Confidence adds context to performance; it does not replace evidence of knowledge.

    Example goal: I will ask students to rate their confidence alongside answers, so that I find confidently held errors and target them.

  5. Actionable feedback Strong evidence baseCore strategy

    Use individual feedback when a precise next action can improve work while the thinking is still live. Make the location, learning issue and required change clear.

    Example goal: I will give one precise next step that students act on straight away, so that students improve their work while the thinking is still fresh.

  6. Feedback tasks Strong evidence base

    Use feedback tasks to make improvement an act of thinking. Select a solvable challenge that helps students locate, explain and repair an issue rather than simply copy a correction.

    Example goal: I will plan time and tasks for students to act on feedback, so that students think about and improve their work rather than just reading comments.

  7. Feedback follow-up Research-informed

    Use feedback follow-up to find out whether the learning improved beyond the original correction. A new attempt gives more useful evidence than a rewritten answer alone.

    Example goal: I will give students a new, similar task after feedback, so that I can see whether learning has improved beyond the corrected piece.

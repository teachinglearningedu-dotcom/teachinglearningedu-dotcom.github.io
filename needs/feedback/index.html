Pupil need

Feedback isn't improving pupils' work

You spend time giving feedback, but the same issues reappear and pupils don't use the comments.

Where to start

Feedback works when pupils act on it. Focus on the most important next step, plan time for pupils to improve, and check the improvement on a new task.

Strategies to consider

Choose one. Start with a core strategy unless another fits your class better.

  1. Whole-class feedback Research-informedCore strategy

    Use whole-class feedback when students’ work reveals shared strengths and recurring difficulties. Review the pattern once, then give everyone a useful improvement task.

    Example goal: I will use whole-class feedback on common strengths and errors followed by an improvement task, so that all students act on feedback efficiently.

  2. Actionable feedback Strong evidence baseCore strategy

    Use individual feedback when a precise next action can improve work while the thinking is still live. Make the location, learning issue and required change clear.

    Example goal: I will give one precise next step that students act on straight away, so that students improve their work while the thinking is still fresh.

  3. Feedback tasks Strong evidence base

    Use feedback tasks to make improvement an act of thinking. Select a solvable challenge that helps students locate, explain and repair an issue rather than simply copy a correction.

    Example goal: I will plan time and tasks for students to act on feedback, so that students think about and improve their work rather than just reading comments.

  4. Feedback follow-up Research-informed

    Use feedback follow-up to find out whether the learning improved beyond the original correction. A new attempt gives more useful evidence than a rewritten answer alone.

    Example goal: I will give students a new, similar task after feedback, so that I can see whether learning has improved beyond the corrected piece.

  5. Self-checking Research-informed

    Use self-checking when students know what quality looks like but do not yet inspect their own work reliably. Teach a specific checking action rather than telling them to “check it”.

    Example goal: I will teach students a specific self-checking routine, so that students find and fix errors in their own work.

  6. The visualiser Research-informed

    Use the visualiser to make student work a shared learning resource. Select a response because it illustrates a useful success, misconception or improvement decision.

    Example goal: I will use the visualiser to discuss and improve selected student work, so that students see what quality looks like and improve their own work.
